## 3. 插件

- 1. 延迟队列插件 - rabbitmq-delayed-message-exchange

- (Githbu 开源地址): <https://github.com/rabbitmq/rabbitmq-delayed-message-exchange>

```sh

# 1. 切换plugins目录
cd plugins

# 2. 安装 weget （！修改对应版本）
wget https://github.com/rabbitmq/rabbitmq-delayed-message-exchange/releases/download/v4.0.2/rabbitmq_delayed_message_exchange-4.0.2.ez

# 3. 启动
rabbitmq-plugins enable rabbitmq_delayed_message_exchange
# 卸载
rabbitmq-plugins disable rabbitmq_delayed_message_exchange
```
