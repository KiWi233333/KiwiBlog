### **1. 受控与非受控组件（React）**

**受控组件**：由 React 状态（`useState`）控制的表单元素，数据单向流动。例如 `<input value={state} onChange={e => setState(e.target.value)} />`，React 能实时掌控其值。

**非受控组件**：使用 `ref` 直接访问 DOM 取值，数据不由 React 管控，适合简单表单或性能要求较高场景。

**对比总结**：

- 受控：可控性强、统一管理、适合复杂交互；
- 非受控：实现简单、性能较优、适合场景简单或迁移旧项目。

### **2. React 性能优化手段 + 常用 Hooks**

#### 性能优化方法

- 使用 `React.memo` 避免函数组件重复渲染
- `useMemo` 缓存计算结果，避免重复计算
- `useCallback` 缓存函数引用，避免子组件不必要更新
- `lazy` + `Suspense` 实现懒加载
- 拆分组件、合理利用虚拟列表（如 `react-window`）
- 使用批处理（`useTransition`）降低用户交互卡顿

#### 常用 Hooks 简述

- `useState`：声明响应式状态
- `useEffect`：副作用处理
- `useRef`：访问 DOM 或保存可变引用
- `useMemo` / `useCallback`：性能优化
- `useContext`：全局状态共享
- `useReducer`：复杂状态逻辑管理
- `useLayoutEffect`：DOM 渲染后立即执行
- `useTransition` / `useDeferredValue`：并发优化

### **3. Vue2 与 Vue3 区别 & 响应式原理**

#### 核心区别

| 项目         | Vue2                    | Vue3                      |
| ------------ | ----------------------- | ------------------------- |
| 响应式       | `Object.defineProperty` | `Proxy`                   |
| 语法         | Options API             | Composition API（更灵活） |
| 性能         | 较低                    | 编译更快，体积更小        |
| TS 支持      | 差                      | 原生支持 TS               |
| Fragment     | 不支持                  | 支持                      |
| Tree-shaking | 不支持                  | 支持                      |

#### 响应式原理

- **Vue2**：通过 `Object.defineProperty` 拦截属性 `get`/`set`，实现数据劫持，不支持新增/删除属性监听。
- **Vue3**：通过 `Proxy` 拦截对象所有操作，天然支持数组、新属性监听，性能更好，结构更清晰。

### **4. Web3 是什么？区块链技术在前端有哪些体现？**

#### Web3 简述

- Web1.0：只读
- Web2.0：读写（中心化平台）
- **Web3.0**：去中心化，基于区块链实现的“用户数据归用户所有”的新形态互联网

#### 区块链在前端的体现

- 使用 Web3.js、Ethers.js 等库连接以太坊钱包（如 MetaMask）
- 实现 DApp 前端：钱包连接、交易签名、合约调用（`contract.methods`）
- NFT 预览、DeFi 可视化面板（如 Uniswap 前端）
- 使用 The Graph 查询链上数据、IPFS 去中心化存储前端资源
- 安全性需注意：前端不能保存私钥，仅做签名请求等非核心逻辑
